# Domain docs

Repo sử dụng bố cục single-context.

## Trước khi khám phá code

- Đọc `CONTEXT.md` ở thư mục gốc nếu tồn tại.
- Đọc các ADR liên quan trong `docs/adr/` nếu tồn tại.
- Nếu các file này chưa tồn tại, tiếp tục mà không coi đó là blocker.

## Dùng đúng từ vựng domain

Khi đặt tên issue, test, giả thuyết hoặc đề xuất refactor, sử dụng thuật ngữ được định nghĩa trong `CONTEXT.md`.

Nếu thuật ngữ cần dùng chưa có trong glossary, xem đó là dấu hiệu cần làm rõ domain thay vì tự tạo nhiều từ đồng nghĩa.

## Xung đột với ADR

Nếu một thay đổi trái với ADR hiện có, phải nêu rõ ADR bị ảnh hưởng và lý do cần xem xét lại thay vì âm thầm ghi đè quyết định.
