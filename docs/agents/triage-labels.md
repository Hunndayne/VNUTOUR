# Triage labels

| Vai trò chuẩn | Nhãn trong repo | Ý nghĩa |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer cần đánh giá |
| `needs-info` | `needs-info` | Đang chờ thêm thông tin |
| `ready-for-agent` | `ready-for-agent` | Đủ đặc tả để agent tự triển khai |
| `ready-for-human` | `ready-for-human` | Cần con người xử lý |
| `wontfix` | `wontfix` | Không triển khai |

Khi skill nhắc đến một vai trò triage, sử dụng nhãn tương ứng trong bảng này.
